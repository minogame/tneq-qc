## 1. TNEQ：用张量网络逼近图

**核心思想**：每张图（graph）对应训练一个张量网络（TN），用 $\langle A|B\rangle$ 度量两个 TN 的相似度，从而用小 TN 逼近/表示一张图的结构。

### 1.1 实验设置

| 项目 | 内容 |
|---|---|
| 任务 | 图逼近：给定一张图，训练一个 TN 使其内积最大化 |
| 数据集 | 若干标准图（MNIST digit graphs、分子图、社交网络子图等）|
| 模型 | `TNEQ`：`MPS_L`（训练） + `MPS_R`（目标图编码，固定）|
| 拓扑 | MPS，bond_dim = 8 / 16 / 32 |
| 优化目标 | 最大化 $\langle A | B_{\mathrm{target}} \rangle$，等价于最小化 $\|A - B\|^2$ |
| 优化器 | SGD-G（Stiefel 流形梯度下降）|

### 1.2 需要提供的结果

- **逼近误差曲线**：$\|A - B\|_F$ vs. 迭代步数（对比 bond_dim = 8 / 16 / 32）
- **收敛速度**：达到误差阈值所需迭代步数
- **可视化**（若图可二维嵌入）：原图邻接矩阵热力图 vs. TN 重建矩阵热力图
- **不同图结构对比**：稀疏图 / 密集图 / 结构化图的逼近质量

## 3. 分布式训练加速比

**目标**：在相同 qubit 数 / 相同模型结构下，对比单节点与多节点的每迭代耗时，定量展示分布式训练的扩展效率。

### 3.1 实验设置

| 项目 | 内容 |
|---|---|
| 固定配置 | 256 qubit，MPS，bond_dim = 32，batch_size = 512 |
| 节点数 | 1、2、4、8（每节点 4 GPU）|
| 总 GPU 数 | 4、8、16、32 |
| 通信协议 | MPI（节点间）+ NCCL（节点内）|
| 测量指标 | 每迭代耗时（ms/step），峰值显存（GB/GPU）|
| 测量方式 | 预热 10 步后，统计 100 步均值 ± 标准差 |

### 3.2 加速比表格

| 节点数 | 总 GPU 数 | ms/step | 加速比 | 并行效率 |
|---|---|---|---|---|
| 1（基准）| 4 | | 1.00× | 100% |
| 2 | 8 | | | |
| 4 | 16 | | | |
| 8 | 32 | | | |

> 并行效率 = 实际加速比 / 理想加速比（节点数）× 100%

### 3.3 加速比折线图

- X 轴：节点数（1 / 2 / 4 / 8，对数坐标）

| 类型 | 格式要求 |

| 概率等高线图 | matplotlib contourf，分辨率 ≥ 300 DPI，含 colorbar |
